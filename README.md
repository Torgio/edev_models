# edev_models

## Pulso Energía — dashboard local del equipo

La web está en `app/` y la API de solo lectura en `api/`.
Para probar los avances sin desplegar en el servidor, seguir la
[guía de arranque local](docs/dashboard_local.md).

El código no incluye datos ni credenciales de PostgreSQL. Cada integrante necesita
acceso autorizado de lectura o una base local con el esquema y los datos necesarios.
Arrancar esta copia no actualiza la web publicada ni instala servicios en el VPS.

La instalación publicada se documenta en el
[manual de despliegue](docs/manual_despliegue_pulso_energia.md).
